# Sipan Danielyan – Personal Website

This repository contains my personal website, built to present my professional background, skills, and services in a clean and modern way.

The site is designed as a lightweight, responsive front-end project with a clear structure and smooth user experience across desktop and mobile devices. It serves as a central place to share information about my work, technical skills, and ways to get in touch.

---

## Overview

This website includes sections for:
- Personal introduction
- Professional background
- Technical skills
- Selected work and services
- Contact information

The focus is on clarity, performance, and maintainability rather than heavy frameworks or unnecessary complexity.

---

## Key Characteristics

- **Clean and modern layout** focused on readability
- **Fully responsive design** for desktop, tablet, and mobile
- **Smooth UI animations** for better user experience
- **Clear section structure** for easy navigation
- **Lightweight and fast loading**
- **Easy to maintain and update**

---

## Technologies Used

- **HTML5** – page structure  
- **Tailwind CSS** – styling and responsive layout  
- **Vanilla JavaScript** – interactivity and animations  
- **AOS (Animate on Scroll)** – scroll-based animations  
- **Lottie** – lightweight vector animations  
- **Google Fonts** – typography  

---

## Project Structure

```
├── index.html          # Main website file
├── styles.css          # Custom styling
├── script.js           # JavaScript logic and animations
├── assets/
│   ├── resume.pdf      # Resume / CV file
│   └── images/         # Images and media
└── README.md           # Project documentation
```

---

## Customization

All content can be updated directly in `index.html`.

Typical updates include:
- Name, title, and introduction text
- Skills and services
- Project descriptions
- Contact information
- Resume file and images

Styling adjustments can be made using Tailwind utility classes or in `styles.css` if needed.

---

## Deployment

This is a static website and can be deployed on any static hosting provider, including:
- GitHub Pages
- Netlify
- Vercel
- Any standard web server

Simply upload the project files or connect the repository to your hosting platform.

---

## Notes

- The contact form is frontend-only and intended as a UI component.
- External libraries are loaded via CDN for simplicity.
- The project is structured to remain easy to extend or adapt in the future.
